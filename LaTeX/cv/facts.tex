%-------------------------------------------------------------------------------
% THE NUMBERS
%
% Every count and metric that appears in more than one place. The publication
% totals, the patent count, the citation metrics and the review totals each used
% to be typed out in three or four files -- summary_cv, summary_resume,
% highlights, publications, activities -- so updating one meant grepping for the
% old value and hoping. They are defined once here instead, and both documents
% input this file.
%
% The publication counts are checked against the .bib files by the build (see
% .github/workflows/build-pdf.yml), so a number edited here without a matching
% bibliography entry fails CI rather than shipping quietly.
%-------------------------------------------------------------------------------
